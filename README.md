# مجمع عيادات النخبة الطبي

صفحة تعريفية ثابتة (HTML/CSS/JS) لمجمع عيادات طبية، مبنية بدون أي أُطر عمل أو اعتماديات خارجية.

## المحتوى
- تعريف بالمجمع ورؤيته
- الأقسام الطبية
- الفريق الطبي
- أوقات العمل وبيانات التواصل

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح، أو استعرض النسخة المنشورة عبر GitHub Pages.

> جميع البيانات في الصفحة تجريبية للعرض فقط.
